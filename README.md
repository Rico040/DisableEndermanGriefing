# Disable Enderman Griefing

Disable Enderman's ability to pick up certain blocks. Made for Minecraft 1.0.0 with [Ornithe](https://ornithemc.net/).

## Usage

Install Ornithe from https://ornithemc.net/ornithe-installer-rs/ and choose Minecraft Version 1.0.0, check `Include Flap`, select Fabric loader.

Download from [Releases](https://github.com/Rico040/DisableEndermanGriefing/releases) jar file and [OSL](https://modrinth.com/mod/osl) and put them in Minecraft's `mods` folder.

## Build

```shell
./gradlew build
```
